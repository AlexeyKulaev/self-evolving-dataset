# Live integration test, not a research benchmark

There is exactly one concept in scope: add two nonnegative integers, then return
the last decimal digit of the result (addition modulo 10). Do not introduce
subtraction, multiplication, or any other domain. Split the provided seed
examples into the one addition domain. The question is a string like 12+8 and
the answer is a one-digit string like 0. Generate new independent instances.
